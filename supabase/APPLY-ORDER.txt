TUINBOOKS V2 — CANONICAL DATABASE INSTALL ORDER

Run against QA/staging Supabase first. Stop immediately on any SQL error.
The application is NOT release-ready unless every REQUIRED step below is installed.

BASE CONTRACT — REQUIRED
1. migration-v2-schedule-mutations.sql
2. migration-v2-recurrence-authority.sql
3. migration-v2-operational-states.sql
4. migration-v2-client-authority.sql
5. migration-v2-work-mobile.sql
6. migration-v2-money-quotes.sql
7. migration-v2-business-import-management.sql
8. migration-v2-release-completion.sql

CURRENT RELEASE CONTRACT — ALSO REQUIRED
9. APPLY-R12-MISSED-VISIT-RESOLUTION.sql
10. APPLY-R13-GROUP-DRAG.sql
11. APPLY-R14-VISIT-DETAIL.sql
12. APPLY-R24-MINI-STRESS-BLOCKERS.sql
13. migration-v2-money-quotes.sql   [RE-RUN — final finance authority]
14. APPLY-R25-SCHEDULE-BASKET.sql

WHY STEP 13 IS INTENTIONAL
R24 expands support/financial access and Planning-only enforcement, but it also replaces several money RPCs. The canonical money migration is deliberately re-runnable and is applied again after R24 so the final database keeps R24's access functions while using the current quote, billing, charge-cancellation, VAT and invoice-visit authority. This avoids a deployment whose behaviour depends on which historical SQL happened to run last.

The old statement that INSTALL-V2-CORE.sql alone represents the entire current database contract is no longer valid. It contains the eight base migrations only. A current deployment must follow this complete order.

Application source and database RPCs must move together. Do not deploy a new frontend against a database that has only part of this list installed.

NOT AUTOMATIC / REVIEW BEFORE RUNNING
- migration-v2-optional-adopt-legacy-recurrence.sql
  Conservative bridge for adopting simple legacy recurrence into the v2 series model. Keep it separate so deployment cannot silently rewrite legacy recurrence.

NOT REQUIRED BY CURRENT SETTINGS
- APPLY-R17-AUDIT-LOG.sql
  Recent activity has been removed from Settings. audit_events remains internal system history, but the R17 Settings reader is no longer a release dependency.
