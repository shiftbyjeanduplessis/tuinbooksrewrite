# TuinBooks v2 — single codebase deployment

This repository is the frozen v2 release candidate.

## What is in this one codebase

- `src/` — complete TypeScript source.
- `dist/` — generated by the build; production route tree is `/app/` and `/management/`.
- `supabase/INSTALL-V2-CORE.sql` — the eight additive v2 core migrations in required order.
- `supabase/migration-v2-optional-adopt-legacy-recurrence.sql` — deliberately separate legacy recurrence adoption bridge.
- `render.yaml` — Render static-site build configuration.
- `tests/` — domain, release-contract, stress, binary XLSX round-trip, static and HTTP gates.
- `windows-qa/` — Windows/Edge QA helper retained for browser verification.

## Build gate

```bash
npm install
npm run check
```

The Render blueprint runs the same gate before publishing `dist/`.

## URL contract

- Office app: `/app/`
- Field/Owner mobile: `/app/mobile.html`
- Management: `/management/`
- Quote response: `/app/accept.html`
- Public invoice/statement: `/app/document.html`

## Database

The frontend requires the v2 RPC/table contract. Apply `supabase/INSTALL-V2-CORE.sql` to QA/staging before testing the live-backed v2 app.

The legacy recurrence adoption bridge is not included in the automatic installer. It must be reviewed and run deliberately because it maps existing routine agreements into the new recurrence authority.

## Honesty gate

This codebase has passed automated source/domain/stress/XLSX/static/HTTP checks. It has not yet been proven through the final deployed real-browser + real-Supabase acceptance run.
